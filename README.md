# Customer Churn Prediction

## 📌 Project Overview

Customer Churn Prediction is a Machine Learning classification project that predicts whether a customer is likely to leave a company.

The project analyzes 7,000+ customer records and identifies important factors that influence customer churn. Different classification models are trained and evaluated to predict high-risk customers.

## 🎯 Objectives

- Analyze customer data using Exploratory Data Analysis (EDA)
- Identify patterns and factors associated with customer churn
- Perform data cleaning and preprocessing
- Apply feature engineering
- Build Machine Learning classification models
- Compare Logistic Regression and Random Forest
- Evaluate models using multiple performance metrics
- Identify important churn-driving features
- Predict whether a new customer is likely to churn

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 🤖 Machine Learning Models

### 1. Logistic Regression

Used as a baseline classification model for predicting customer churn.

### 2. Random Forest

Used as a tree-based ensemble classification model to improve prediction performance and identify important features.
